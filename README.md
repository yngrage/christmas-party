# A Very Merry Gathering

A responsive, single-page Christmas invitation with a built-in holiday memory game. It uses plain HTML, CSS, and JavaScript, so it can be hosted on GitHub Pages without a build step.

## Personalize the invitation

Edit `index.html` to replace the date, time, location, host, RSVP deadline, and `you@example.com` address. Search for `coming soon`, `Your host here`, `[RSVP date]`, and `you@example.com` to find each placeholder.

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub will provide the public site URL after deployment.
