# Christmas with the Fernandes Family

A phone-first Christmas invitation with a red and green holiday theme, black-tie dress code, pinned map preview, Google Maps directions, and WhatsApp RSVP handoff. Built with plain HTML, CSS, and JavaScript for GitHub Pages.

## RSVP flow

Guests enter their name, mobile number, party size, overnight stay preference, optional email, and dietary or accessibility notes. The site opens WhatsApp with those details addressed to the host. Guests review the message and tap **Send**; the website does not send an automatic reply or retain RSVP submissions.

## Event details

Saturday, 26 December 2026, from 8 PM onwards. Hosted by the Fernandes Family. Dress code: black tie. The Google Maps share link and RSVP WhatsApp number are in `script.js`.
